TE / GR / v3 Key Structures

TE Opaque LSA (RFC 3630) sub-TLVs
1 Link Type (P2P/Multi-access)
2 Link ID
3/4 Local/Remote IP
6 Max Bandwidth (float)
7 Max RSVP Bandwidth
8 Unreserved BW ×8 priorities
9 TE Metric
10 Admin Group (color)
15 SRLG values (RFC 4203)
Graceful Restart TLVs (RFC 3623)
TLV 1 Grace Period (seconds, max 1800) 4 bytes
TLV 2 Restart Reason (0=Unknown…3=Redundant CP) 1 byte
TLV 3 IP Interface Address (optional) 4 bytes
OSPFv3 vs v2 Key Differences
Header: 24→16 bytes · Instance ID added · No auth
Hello: No network mask · Interface ID field
LSA type: 8-bit → 16-bit (flooding scope in bits 14-15)
New LSAs: Link-LSA (0x0008) · Intra-Area-Prefix (0x2009)
Multicast: 224.0.0.5 → ff02::5 · 224.0.0.6 → ff02::6
